原理 七、理解的原理

  • entities vs Primitive 性能差异（单个对象 vs 批量 GPU 渲染）
  • 深度缓冲：离相机近的物体遮挡远的
  • GPU 并行：几千核心同时画不同像素，互不干扰
  • ModelInstanceCollection：同一模型复用显存
  • 3D Tiles：海量数据瓦片化，视锥体裁剪
  • 着色器：GPU 上跑的小程序，顶点着色器算位置，片元着色器算颜色

十、WebGIS 场景题：大规模数据怎么处理

场景方案
10 万条 GeoJSON 直接加载卡死切成矢量瓦片（.mvt），按视野加载当前块；或用 tippecanoe 转成 .pbf 瓦片
10 万个点一次性渲染，浏览器崩溃Web Worker 开线程处理数据；聚类（Supercluster）；视口裁剪
1 万个 3D 模型，显卡扛不住3D Tiles 瓦片化 + LOD；ModelInstanceCollection 复用显存；远处用 Billboard 代替
地形分析采样 1000 次太慢控制采样频率；结果缓存；降低精度（30 米 DEM）
GeoJSON 属性太多，文件 50MB只传需要的字段；TopoJSON 压缩 80%；数据分页
地图瓦片加载慢，白块多CDN 加速；预加载相邻瓦片；降低瓦片质量

了解 十一、OGC 地理信息服务

服务类型全称 / 做什么的
WMSWeb Map Service，返回地图图片，请求参数：layers、bbox、width、height
WMTSWeb Map Tile Service，返回预切好的瓦片，比 WMS 快
WFSWeb Feature Service，返回矢量数据（GeoJSON/GML），支持增删改查
WCSWeb Coverage Service，返回栅格数据（DEM、温度），可以做分析
WPSWeb Processing Service，在线地理处理，提交数据跑算法
OGC制定这些标准的地组织，WMS/WMTS/WFS/WCS 都是 OGC 定义的协议

十三、构建工具：Vite vs Webpack

概念说明
Vite开发用 ES Module 不打包秒启动；生产用 Rollup 打包；你项目用的就是这个
Webpack开发也要打包，项目大了启动慢；插件生态丰富，老项目用得多
区别Vite 快（开发不打包），Webpack 慢但成熟；Vite 更适合 Vue 3 新项目
常见配置alias：@ 指向 src；proxy：跨域代理；build：输出目录、压缩、代码分割

十四、组件封装

概念说明

Props数据父传子，定义类型和默认值；单向数据流，子组件不直接改 props
Emit子组件通过 emit 通知父组件，例：emit('update:modelValue', val)
v-modelprops + emit 的语法糖，子组件 props.modelValue + emit('update:modelValue')
插槽（slot）父组件往子组件插内容：默认插槽、具名插槽、作用域插槽
Composable逻辑抽到 .js 文件复用，如 useVehicleSimulation、usePointPerformance

二十四、浏览器存储

类型说明
localStorage持久存储，关浏览器不丢，存 token、用户偏好；setItem/getItem/removeItem
sessionStorage关标签页就丢，存临时状态
Cookie每次请求自动带，存 sessionId、登录态；可设 HttpOnly（防 XSS）、Secure（仅 HTTPS）
IndexedDB容量大，异步操作，适合离线缓存、地图瓦片缓存
区别localStorage 持久、sessionStorage 关页丢；Cookie 自动带请求；IndexedDB 存大文件

二十五、HTTP 缓存

概念说明
强缓存浏览器直接用缓存不问服务器；Cache-Control: max-age=3600；适合地图瓦片、图片、带 hash 的 CSS/JS
协商缓存浏览器问服务器"过期了吗"；没过期 → 304 继续用；过期 → 200 返回新内容
F5 vs Ctrl+F5F5 走协商缓存；Ctrl+F5 跳过所有缓存
地图瓦片缓存设 max-age=31536000（一年）；瓦片 URL 带版本号，更新时改 URL

二十六、Web 安全基础

概念说明
XSS（跨站脚本）注入 script 偷 cookie；防御：转义、CSP；前端 v-html 谨慎用，用 DOMPurify 过滤
CSRF（跨站请求伪造）伪造用户请求；防御：SameSite Cookie、CSRF Token
SQL 注入输入框写 SQL 篡改数据库；防御：参数化查询，JPA 默认就安全
HTTPS加密传输，生产环境必须上
CORS跨域限制，后端设 Access-Control-Allow-Origin；开发时 Vite proxy 代理绕过

二十七、终端与 Shell（Windows 环境）

概念说明
CMDWindows 最老终端，dir 列文件、cd 切换、del 删除；不支持 Linux 命令
PowerShell微软新一代终端；Get-ChildItem、Remove-Item；支持脚本 .ps1、管道；你项目 npm run dev 就在这跑
Bash / Git BashLinux 风格终端，装 Git 自带；ls、rm、grep、cat 全能用；和 Linux 服务器一致
Windows Terminal一个窗口同时开 CMD/PowerShell/Bash；支持分屏、主题、GPU 加速
命令对比列文件：dir / ls / Get-ChildItem；删除：del / rm / Remove-Item；查看：type / cat；搜索：findstr / grep
