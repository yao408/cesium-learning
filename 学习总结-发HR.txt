七、理解的原理
----------------------------------------------------------------
entities vs Primitive 性能差异（单个对象 vs 批量 GPU 渲染）
深度缓冲：离相机近的物体遮挡远的
GPU 并行：几千核心同时画不同像素，互不干扰
ModelInstanceCollection：同一模型复用显存
3 Tiles：海量数据瓦片化，视锥体裁剪

十、WebGIS 场景题：大规模数据怎么处理
----------------------------------------------------------------
场景                                    | 方案
10 万条 GeoJSON 直接加载卡死             | 切成矢量瓦片（.mvt），按视野加载当前块
                                        | 或者用 tippecanoe 转成 .pbf 瓦片
10 万个点一次性渲染，浏览器崩溃           | Web Worker 开线程处理数据，不卡主线程
                                        | 聚类（Supercluster）：远处合并，近处展开
                                        | 视口裁剪：只渲染屏幕范围内的点
1 万个 3D 模型，显卡扛不住               | 3D Tiles 瓦片化 + LOD（远处用低精度模型）
                                        | ModelInstanceCollection 复用同一模型显存
                                        | 远处模型用 Billboard 图标代替
地形分析（通视/坡度）采样 1000 次太慢     | 控制采样频率，不是每一个像素都采样
                                        | 结果缓存：相同两点不重复计算
                                        | 降低精度：用 30 米 DEM 不用 10 米
GeoJSON 属性太多，文件 50MB               | 只传需要的字段，后端过滤
                                        | 前端用 TopoJSON 代替 GeoJSON（压缩 80%）
                                        | 数据分页：每次只加载 1000 条
地图瓦片加载慢，白块多                    | CDN 加速瓦片 URL
                                        | 预加载相邻瓦片（地图移动时提前加载）
                                        | 降低瓦片质量（retina → 普通）


十一、OGC 地理信息服务（了解概念，未在项目中使用）
----------------------------------------------------------------
服务类型                                | 全称 / 做什么的
WMS                                    | Web Map Service，返回地图图片（PNG/JPEG）
                                        | 请求参数：layers、bbox、width、height
                                        | 例：http://server/wms?request=GetMap&layers=roads&bbox=104,31,105,32&width=800&height=600
WMTS                                   | Web Map Tile Service，返回预切好的瓦片
                                        | 比 WMS 快，因为瓦片是提前生成好的
                                        | 类似地图底图的工作方式，z/x/y 行列号
WFS                                    | Web Feature Service，返回矢量数据（GeoJSON/GML）
                                        | 不只是看图，还能增删改查要素
                                        | 例：request=GetFeature&typeName=roads&bbox=...
WCS                                    | Web Coverage Service，返回栅格数据（DEM、温度、降雨）
                                        | 不是图片，是带数值的数据，可以做分析
WPS                                    | Web Processing Service，在线地理处理
                                        | 提交数据 → 服务器跑算法 → 返回结果
                                        | 例：缓冲区分析、路径计算、插值
OWS 与 OGC 的关系                       | OGC 是制定这些标准的地组织
                                        | WMS/WMTS/WFS/WCS 都是 OGC 定义的协议
                                        | OWS = OGC Web Services 的统称


十二、前端通用场景题
----------------------------------------------------------------
场景                                    | 方案
首屏加载 5 秒，用户等不了                 | 路由懒加载：import() 按需加载页面
                                        | 组件异步加载：defineAsyncComponent
                                        | 第三方库按需引入：Cesium 只引入用到的模块
                                        | 图片懒加载、压缩、WebP 格式
                                        | CDN 托管静态资源
页面卡顿，操作不跟手                     | 计算密集任务放 Web Worker
                                        | 防抖（搜索输入 300ms 后再请求）
                                        | 节流（滚动事件 100ms 最多触发一次）
                                        | 虚拟列表：1 万条数据只渲染可见的 20 条
                                        | requestAnimationFrame 代替 setInterval
接口返回 1 万条数据，前端怎么展示         | 后端分页：page=1&size=20，只返回 20 条
                                        | 前端分页：拿到全部数据，前端自己切页
                                        | 无限滚动：触底加载下一页（IntersectionObserver）
                                        | 虚拟列表：长列表只渲染可视区域
同时发 10 个接口，页面等太久              | Promise.all 并发请求（但一个失败全部失败）
                                        | Promise.allSettled 一个失败不影响其他的
                                        | 按优先级分批：核心数据先加载，次要后加载
                                        | 骨架屏占位，先给用户看结构
切换页面再回来，之前的状态丢了            | KeepAlive 缓存组件（你项目里用了）
                                        | 数据存 Pinia/Vuex，不随组件销毁
                                        | URL 参数保存筛选条件，刷新也能恢复
用户重复点击按钮，发了 10 次请求          | 按钮 loading 状态，点击后 disabled
                                        | 防抖：2 秒内只触发一次
                                        | 请求去重：相同请求进行中时不重复发
内存泄漏，页面越用越卡                   | 组件卸载时清理定时器、事件监听
                                        | Cesium 实体/图元 remove 后再 destroy
                                        | 闭包引用：不需要的变量置 null
                                        | WeakMap 存 DOM 引用，DOM 删了自动回收
跨域请求被浏览器拦截                     | 后端配 CORS 允许前端域名
                                        | 开发环境用 Vite proxy 代理
                                        | 生产环境 Nginx 反向代理
登录过期，用户操作到一半被踢出去          | 路由守卫 beforeEach 检查 token
                                        | 响应拦截器：401 自动跳登录页
                                        | 刷新 token：accessToken 过期用 refreshToken 续
                                        | 保存当前操作，登录后恢复到之前页面

十九、Three.js（了解概念，未在项目中使用）
----------------------------------------------------------------
概念                                    | 说明
Three.js 是什么                         | 纯 WebGL 封装库，在浏览器里画任何 3D 东西
                                        | 不限于地图，能做游戏、产品展示、数据可视化
与 Cesium 的区别                        | Three.js 是通用 3D 引擎，什么都能画
                                        | Cesium 是专门的地球引擎，自带地图、地形、坐标
                                        | Three.js 更适合自定义 3D 场景（室内、产品）
                                        | Cesium 更适合地理空间场景（地球、GIS 分析）
核心三要素                              | Scene（场景）：所有物体的容器
                                        | Camera（相机）：从哪个角度看
                                        | Renderer（渲染器）：把场景画到屏幕上
几何体（Geometry）                      | BoxGeometry：立方体
                                        | SphereGeometry：球体
                                        | PlaneGeometry：平面
                                        | BufferGeometry：自定义顶点（最灵活）
材质（Material）                        | MeshBasicMaterial：不受光，纯色
                                        | MeshStandardMaterial：PBR 物理光照，最真实
                                        | MeshPhongMaterial：镜面反射
                                        | ShaderMaterial：自定义着色器（最灵活）
光照（Light）                           | AmbientLight：环境光，均匀照亮
                                        | DirectionalLight：平行光（太阳光）
                                        | PointLight：点光源（灯泡）
                                        | SpotLight：聚光灯（手电筒）
纹理（Texture）                         | 给模型贴图，皮肤/墙面/地面
                                        | TextureLoader 加载图片
                                        | 支持法线贴图、粗糙度贴图、金属度贴图
动画循环                               | requestAnimationFrame 每帧更新
                                        | 旋转：mesh.rotation.x += 0.01
                                        | 移动：mesh.position.x += 0.1
加载 GLB/GLTF 模型                      | GLTFLoader 加载外部 3D 模型
                                        | 和 Cesium 的 Model.fromGltfAsync 本质一样
                                        | 都是解析 glTF 格式，丢给 GPU 渲染
Three.js 和 Cesium 能一起用吗           | 可以，但通常不这么做
                                        | Cesium 内置了 Three.js 类似的能力
                                        | 除非需要 Cesium 没有的特殊效果

二十四、浏览器存储
----------------------------------------------------------------
类型                                    | 说明
localStorage                            | 持久存储，关浏览器不丢，存 token、用户偏好
                                        | setItem / getItem / removeItem
sessionStorage                          | 关标签页就丢，存临时状态
Cookie                                  | 每次请求自动带，存 sessionId、登录态
                                        | 可设 HttpOnly（防 XSS）、Secure（仅 HTTPS）
IndexedDB                               | 容量大，异步操作，适合离线缓存、地图瓦片缓存
区别                                    | localStorage 持久、sessionStorage 关页丢
                                        | Cookie 自动带请求、IndexedDB 存大文件


二十六、HTTP 缓存
----------------------------------------------------------------
概念                                    | 说明
强缓存                                  | 浏览器直接用缓存，不问服务器
                                        | Cache-Control: max-age=3600（秒）
                                        | 适合：地图瓦片、图片、带 hash 的 CSS/JS
协商缓存                                | 浏览器问服务器"过期了吗？"
                                        | 没过期 → 304，继续用缓存
                                        | 过期 → 200，返回新内容
F5 vs Ctrl+F5                           | F5 走协商缓存，Ctrl+F5 跳过所有缓存
地图瓦片缓存                            | 设 max-age=31536000（一年）
                                        | 瓦片 URL 带版本号，更新时改 URL


二十七、Web 安全基础
----------------------------------------------------------------
概念                                    | 说明
XSS（跨站脚本）                         | 注入 script 偷 cookie，防御：转义、CSP
                                        | 前端 v-html 谨慎用，用 DOMPurify 过滤
CSRF（跨站请求伪造）                    | 伪造用户请求，防御：SameSite Cookie、CSRF Token
SQL 注入                                | 输入框写 SQL 篡改数据库
                                        | 防御：参数化查询，JPA 默认就安全
HTTPS                                   | 加密传输，生产环境必须上
CORS                                    | 跨域限制，后端设 Access-Control-Allow-Origin
                                        | 开发时 Vite proxy 代理绕过


二十七、终端与 Shell（Windows 环境）
----------------------------------------------------------------
概念                                    | 说明
CMD（命令提示符）                       | Windows 最老的终端，基于 DOS
                                        | dir 列文件、cd 切换目录、del 删除
                                        | 不支持 Linux 命令（ls、rm、grep 不能用）
PowerShell                              | 微软新一代终端，功能更强
                                        | Get-ChildItem 列文件、Remove-Item 删除
                                        | 支持脚本 (.ps1)、管道、面向对象
                                        | 你项目 npm run dev 就在 PowerShell 跑
Bash / Git Bash                         | Linux 风格终端，装 Git 时自带
                                        | ls、rm、grep、cat 全能用
                                        | 前端开发常用，和 Linux 服务器一致
Windows Terminal                        | 微软新终端软件，一个窗口同时开 CMD/PowerShell/Bash
                                        | 支持分屏、主题、GPU 加速
常用命令对比                            | 列文件：dir（CMD）/ ls（Bash）/ Get-ChildItem（PS）
                                        | 删除：del（CMD）/ rm（Bash）/ Remove-Item（PS）
                                        | 查看内容：type（CMD）/ cat（Bash）
                                        | 搜索：findstr（CMD）/ grep（Bash）
                                        | 环境变量：set（CMD）/ echo $VAR（Bash）/ $env:VAR（PS）
                                        | npm 命令三通用，推荐 PowerShell 或 Git Bash
